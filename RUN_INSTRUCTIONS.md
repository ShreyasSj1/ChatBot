# Run Instructions

## 1) Install dependencies

```bash
pip install flask
```

If `pip` maps to Python 2, use:

```bash
pip3 install flask
```

## 2) Start the application

```bash
python app.py
```

If `python` is not available, use:

```bash
python3 app.py
```

## 3) Open in browser

Visit:

`http://127.0.0.1:5000`

- User IDs: `1`, `2`, `3`, `4`, `5`
