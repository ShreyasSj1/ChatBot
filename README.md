## Swiggy-style Chatbot (Flask + SQLite + Gemini)

### Run

```bash
pip install flask requests
python app.py
```

If `python` is not available in your shell, use:

```bash
python3 app.py
```

### Demo Login

- User IDs: `1` to `5`
- Passwords: `pass1` to `pass5`

### Gemini Key

Set your key in:

- `app.py` → `GEMINI_API_KEY = "PASTE_YOUR_GEMINI_API_KEY_HERE"`
